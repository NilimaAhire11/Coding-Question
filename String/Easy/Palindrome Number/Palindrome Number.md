## Palindrome Number

**Problem Statement :- Check if a string is palindrome or not**

**Example 1:**

Input: s = "racecar"

Output: true

Explanation: "racecar" reads the same forwards and backwards, so it is a palindrome..


**Example 2:**

Input: s = nilima"

Output: false

Explanation: "nilima" does not read the same forwards and backwards, so it is not a palindrome.
