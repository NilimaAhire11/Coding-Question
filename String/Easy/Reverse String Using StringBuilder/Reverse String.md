## Reverse a Given String Using StringBuilder

**Given a string s, reverse the string. Reversing a string means rearranging the characters such that the first character becomes the last,
the second character becomes second last and so on.**

**Example 1:-** 

Input: s = "Hello"

Output: "olleH"

Explanation : The first character H moves to last position, the second character e moves to second-last and so on.
